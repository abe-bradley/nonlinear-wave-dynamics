COLORMAP DATA AND THIRD-PARTY NOTICES

The ot_colormap interface supplies colors from the user's installed MATLAB
or from the reviewed external tables distributed with this project. Palette
designs remain credited to their creators. The new interface does not change
the licenses of the external material. No license for the research project's
own code is selected by this file.

The per-palette catalog is:
MATLAB/Functions/Plotting/Colormaps/data/palette_catalog.json
The external RGB tables are:
MATLAB/Functions/Plotting/Colormaps/data/external_palettes.mat
Original license texts and source notices accompany this file in
LICENSES/. They must travel with redistributed external data.

PACKAGING AND INTERFACE CHANGES

- MATLAB-native names are resolved to installed MATLAB functions. Their
  copied tables are omitted from external_palettes.mat.
- The colorblind entry and its RGB data are omitted. Original slanCM ID 192
  is absent; the remaining original IDs are not renumbered.
- The interface, catalog, and data packaging were written for this project.
  Name aliases and original numeric IDs are recorded in the catalog.
- External tables retain their stored precision. The interface linearly
  interpolates these tables to the requested number of colors, as slanCM did.
- Native palettes follow installed MATLAB output at the requested length.
  Their colors can vary with MATLAB release and need not reproduce the old
  slanCM snapshots exactly.
- Plotting code may reverse or apply power/square-root transformations to
  returned colors. In particular, the trajectory plot reverses Colorcet's
  thermal-2/bmy palette; correlation plots reverse CMasher's redshift palette.

MATLAB-native palette data are generated at runtime. MATLAB is a separate
MathWorks product and is not distributed by this project. The original local
slanCM archive under Packages/slanCM_original and audit files under .temp are
not part of the intended public release and are not covered by this external
data packaging description. Do not publish those folders as part of it.
